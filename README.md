# Computer Vision Training Practice · CV Практикум

Локальное приложение для подготовки к экзамену по пяти урокам компьютерного зрения МФТИ. 64 конспекта, 117 вопросов и три цветовые темы.

## Темы оформления

Переключатель **«Цветовая тема»** находится в верхней панели:

- **Неон · тёмная** — глубокий тёмный фон, бирюзовые и фиолетовые акценты, мягкое свечение. Тема по умолчанию.
- **Неон · светлая** — светлый фон, фиолетовые и циановые акценты.
- **Спокойная** — исходное оформление с зелёными акцентами.

Выбор применяется сразу и сохраняется отдельно от учебной статистики. Сброс прогресса не сбрасывает оформление.

## Запуск

Дважды щёлкните **`Открыть практикум.html`** или **`start.cmd`**. Откроется `dist/index.html` в браузере. Установка, интернет, Python, npm и API-ключи для этого не нужны. Всю папку `cv-exam` нужно хранить вместе: внутри находятся тексты, скрипты, шрифты и иллюстрации.

Если браузер ограничивает localStorage для локальных файлов, используйте необязательный сервер:

```powershell
python -X utf8 serve.py
```

Он слушает только `127.0.0.1:8765`. Другой порт: `python serve.py --port 8766`. Остановка — Ctrl+C. Режим HTML и серверный режим имеют разные браузерные хранилища: для переноса статистики используйте экспорт и импорт.

## Что внутри

| Урок | Темы конспекта | Вопросы |
|---|---:|---:|
| 1. Обработка изображений | 13 | 24 |
| 2. Классическое CV и геометрия | 10 | 20 |
| 3. CNN и обучение | 13 | 24 |
| 4. Трансформеры в CV | 16 | 28 |
| 5. Детекция объектов | 12 | 21 |
| Всего | **64** | **117** |

- Определение, механизм, формула там, где нужна, простой пример и типичная ошибка в каждом конспекте.
- 64 вопроса на рассуждение, 20 расчётных, 14 с одним вариантом, 10 с несколькими, 9 коротких определений.
- После ответа — эталон, пример и ссылка на точные ячейки ноутбука. Варианты ответов перемешиваются.
- Для рассуждений — критерии и самостоятельная оценка «пока не знаю / частично / смог объяснить». Приложение не использует языковую модель и не выдаёт проверку по ключевым словам за понимание смысла.
- Короткие определения проверяются по списку допустимых синонимов с игнорированием регистра, пунктуации и различия е/ё. Правильную нестандартную формулировку можно засчитать вручную после сверки с эталоном.
- В числах принимаются точка, запятая и дроби вроде `1/3`. Набор верных вариантов для multi-select должен совпасть целиком.
- Избранное, поиск, повторение ошибок, расписание повторения (10 минут / 1 день / 3 дня), восстановление незавершённой сессии, экспорт и импорт прогресса.
- В личной копии можно подключить полные 13 ноутбуков: 498 непустых ячеек, локальные иллюстрации и сохранённые графические результаты. Исходный код можно читать, но приложение его не запускает.

В смешанной тренировке вопросы из разных уроков чередуются: билет из 15 вопросов включает по 3 из каждого урока, если фильтр оставляет достаточно вопросов во всех пяти темах.

## Публичный репозиторий и личные материалы

Публичная версия запускается сразу: в ней есть интерфейс, конспекты и банк вопросов. Полные тексты ноутбуков, домашние решения, изображения курса и личный прогресс в репозиторий не включаются. Файл `dist/sources.js` содержит только названия, номера уроков и сведения для ссылок на источники.

Если у вас есть локальная папка курса, подключите её:

```powershell
python -X utf8 tools/build_sources.py --course "ПУТЬ_К_ПАПКЕ_КУРСА"
```

Скрипт сохраняет тела ноутбуков в `dist/local/`, а иллюстрации — в `dist/assets/`. Обе папки исключены через `.gitignore`. В вашей исходной рабочей копии материалы уже подключены. Страница ноутбука загружает его при открытии; без локальных файлов показывает инструкцию подключения. Конспекты и тренировка работают независимо от них.

## Точность и область материала

Область вопросов ограничена темами `lesson_1`…`lesson_5` из папки `cv_course_at_mipt`. Использован локальный вариант курса на дату снимка **18.10.2026**. Список экзаменационных тем последующих уроков не добавлялся в банк вопросов. Авторы курса и лицензии компонентов указаны в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

Каждый конспект и вопрос имеет ссылку на файл и номера ячеек (нумерация с 1). Во вкладке «Полные ноутбуки» приведена **исходная запись**, в том числе незавершённые примеры и неточности. Её нельзя считать заново проверенным учебником. Эталонные формулировки находятся в конспектах. Раздел «Уточнения к материалам» отдельно описывает 14 групп исправлений и содержит ссылки на первоисточники.

В частности, уточнены: RoPE и экстраполяция; эквивариантность attention; causal/text masking и label masking; BERT и добавление новой `[MASK]`-позиции; scale и bias SigLIP; M-RoPE; logits-входы функций потерь; hard negatives SSD; два разных CenterNet. Неподтверждённые benchmark-таблицы и слухи об архитектурах закрытых моделей не используются как вопросы. Предметная сверка не является независимой экспертизой всех строк кода исходных ноутбуков.

Первичные источники для спорных мест:

- [BERT](https://aclanthology.org/N19-1423/), [RoFormer](https://arxiv.org/abs/2104.09864), [Positional Interpolation](https://arxiv.org/abs/2306.15595).
- [SigLIP](https://arxiv.org/abs/2303.15343), [NaViT](https://arxiv.org/abs/2307.06304), [Qwen2-VL / M-RoPE](https://arxiv.org/abs/2409.12191).
- [SSD](https://arxiv.org/abs/1512.02325), [CenterNet: Objects as Points](https://arxiv.org/abs/1904.07850), [DETR](https://arxiv.org/abs/2005.12872).
- [PyTorch: attention masks](https://docs.pytorch.org/docs/stable/generated/torch.nn.functional.scaled_dot_product_attention.html), [BCEWithLogitsLoss](https://docs.pytorch.org/docs/stable/generated/torch.nn.BCEWithLogitsLoss.html), [OpenCV: filter2D](https://docs.opencv.org/4.x/d4/d86/group__imgproc__filter.html).

## Данные и автономность

Работа приложения не вызывает сетевых запросов. Markdown и формулы отображаются локальными Marked 15.0.12 и KaTeX 0.16.22; лицензии находятся в `dist/vendor`. Внешние изображения из ноутбуков заменены ссылками; прикреплённые и сохранённые локальные изображения доступны без сети. Внешний источник откроется в новой вкладке только по вашему нажатию.

Ответы, оценки и избранное остаются в localStorage вашего браузера. Перемещение папки или открытие в другом браузере может создать отдельное хранилище, поэтому периодически выгружайте JSON в «Мой прогресс». Импорт проверяет структуру данных, заменяет статистику и избранное после подтверждения и сбрасывает текущую сессию. Исходные ноутбуки приложение не изменяет. Автоматической синхронизации с новыми версиями курса нет.

## Обновление и проверка

Редактируемый банк: `tools/content.py`. Сборка статических данных:

```powershell
python -X utf8 tools/build_sources.py
python -X utf8 tools/content.py
python -X utf8 tools/check_content.py
node --check dist/app.js
node --check dist/core.js
```

Без аргументов `build_sources.py` ищет курс в соседней структуре `CV_MIPT/cv_course_at_mipt`. Для другого расположения используйте `--course`. Скрипт читает ноутбуки и копирует только материал для локального просмотра, не запуская код.

Базовые проверки работают и без папки курса:

```powershell
python -X utf8 tools/check_content.py
node tools/qa.cjs --core-only
node --check dist/themes.js
```

Для браузерной проверки нужен Playwright и Chromium:

```powershell
node tools/qa.cjs <путь-к-пакету-playwright> <путь-к-chromium>
```

Проверяются все конспекты, все ноутбуки, 5 форматов ответа, сохранение сессии, итоговый разбор, экспорт/импорт и мобильная навигация. Тест запускает отдельный временный браузерный контекст и не меняет ваш учебный прогресс. Снимки интерфейса сохраняются в `qa`.
