# Computer Vision Training Practice · CV Практикум

Локальное приложение для подготовки к экзамену по пяти урокам компьютерного зрения МФТИ. 65 конспектов, 457 вопросов и три цветовые темы.

Онлайн-версия: **[cv-training.web.app](https://cv-training.web.app)**.

## Firebase и GitHub

Сайт опубликован на Firebase Hosting. Push в `main` автоматически обновляет его после успешных jobs `check` и `examples` в GitHub Actions. Для pull request выполняются проверки. Настройки: `firebase.json`, `.firebaserc` и `.github/workflows/check.yml`.

GitHub получает временные права через Google Workload Identity Federation: отдельный аккаунт `github-hosting` имеет роли Firebase Hosting Admin и Service Usage Consumer. Вход ограничен числовыми ID этого репозитория и владельца, веткой `main` и событием `push`. Постоянные ключи сервисного аккаунта и Firebase-токены не используются. Проект — `cv-training-practice-mipt`, Hosting target — `practice`, сайт — `cv-training`.

Перед публикацией `python tools/package_hosting.py` собирает `.publish/site` только из разрешённых файлов `dist`, отслеживаемых Git. Локальные ноутбуки и изображения исключены из сборки; неожиданные или устаревшие файлы останавливают публикацию. Все маршруты используют `#`, поэтому отсутствующие файлы возвращают 404 без подмены главной страницей.

Для ручного обновления нужны Python, Git, Node.js 22+ и Firebase CLI 15.26.0:

```powershell
firebase login
firebase deploy --only hosting:practice --project cv-training-practice-mipt
```

**Перенос прогресса:** на прежнем локальном сайте откройте «Мой прогресс» → «Экспорт», затем импортируйте JSON в онлайн-версии. Браузер хранит данные отдельно для каждого адреса. На Firebase прогресс также остаётся в вашем браузере; синхронизации между устройствами нет.

## Темы оформления

Переключатель **«Цветовая тема»** находится в верхней панели:

- **Неон · тёмная** — глубокий тёмный фон, бирюзовые и фиолетовые акценты, мягкое свечение. Тема по умолчанию.
- **Неон · светлая** — светлый фон, фиолетовые и циановые акценты.
- **Спокойная** — исходное оформление с зелёными акцентами.

Выбор применяется сразу и сохраняется отдельно от учебной статистики. Сброс прогресса не сбрасывает оформление.

## Запуск

Дважды щёлкните **`Открыть практикум.html`** или **`start.cmd`**. Откроется `dist/index.html` в браузере. Установка, интернет, Python, npm и API-ключи для этого не нужны. Всю папку `cv-exam` нужно хранить вместе: внутри находятся тексты, скрипты, шрифты и иллюстрации.

Если браузер ограничивает localStorage для локальных файлов, используйте необязательный сервер:

```powershell
python -X utf8 serve.py
```

Он слушает только `127.0.0.1:8765`. Другой порт: `python serve.py --port 8766`. Остановка — Ctrl+C. Режим HTML и серверный режим имеют разные браузерные хранилища: для переноса статистики используйте экспорт и импорт.

- Определение, механизм, формула там, где нужна, простой пример и типичная ошибка в каждом конспекте.
- Во всех 65 темах — раздел «Математика и вывод»: LaTeX, обозначения, условия применимости и пояснения. Для 93 численных задач добавлено отдельное решение формулой.
- Во всех темах — короткий пример Python: функции OpenCV/NumPy, классы PyTorch, loss, masks, rotary embeddings, pooling и matching. Код сопровождается размерами входов, ссылкой на лекцию и указанием того, какие части полной модели опущены. Кнопка копирования переносит обычный текст Python.
- 40 интерактивных схем архитектур и компонентов, 241 блок с пояснениями. Откройте «Схемы моделей» в меню или схему прямо в конспекте. Нажатие на блок показывает его роль и входы/выходы; поддерживается Enter/Space. Схему можно раскрыть целиком, а связи прочитать отдельным списком.
- 279 вопросов на рассуждение, 93 расчётных, 48 с одним вариантом, 28 с несколькими, 9 коротких определений.
- После ответа — эталон, пример и ссылка на точные ячейки ноутбука. Варианты ответов перемешиваются.
- Для рассуждений — критерии и самостоятельная оценка «пока не знаю / частично / смог объяснить». Приложение не использует языковую модель и не выдаёт проверку по ключевым словам за понимание смысла.
- Короткие определения проверяются по списку допустимых синонимов с игнорированием регистра, пунктуации и различия е/ё. Правильную нестандартную формулировку можно засчитать вручную после сверки с эталоном.
- В числах принимаются точка, запятая и дроби вроде `1/3`. Набор верных вариантов для multi-select должен совпасть целиком.
- Избранное, поиск, повторение ошибок, расписание повторения (10 минут / 1 день / 3 дня), восстановление незавершённой сессии, экспорт и импорт прогресса.
- В личной копии можно подключить полные 13 ноутбуков: 498 непустых ячеек, локальные иллюстрации и сохранённые графические результаты. Исходный код можно читать, но приложение его не запускает.

В смешанной тренировке вопросы из разных уроков чередуются: билет из 15 вопросов включает по 3 из каждого урока, если фильтр оставляет достаточно вопросов во всех пяти темах.

## Подробная практика по трансформерам

В уроках появились отдельные банки, а в настройках тренировки — фильтр «Архитектура или основы». Можно выбрать 30, 50 или все подходящие вопросы. В конспектах архитектур добавлены подробные объяснения механизмов, преимуществ и ограничений. Идентификаторы прежних 117 вопросов сохранены, поэтому старый прогресс продолжает работать.

| Банк | Вопросов |
|---|---:|
| BERT | 32 |
| Vision Transformer (ViT) | 33 |
| Swin Transformer | 42 |
| CLIP | 32 |
| CoCa | 31 |
| SigLIP | 32 |
| NaViT | 32 |
| SigLIP2 / NaFlex | 30 |
| Mixture of Experts (MoE) | 31 |
| DETR (урок 5) | 32 |
| Основы Transformer, RoPE и KV-cache | 43 |

Это 340 новых задач в дополнение к исходному банку. В Swin несколько задач посвящены пути обмена через shifted windows, циклическому сдвигу, маскам границ и padding, relative position bias, иерархии, patch merging и числу attention-пар. Остальные банки также сочетают определения, объяснения, сравнения, поиск ошибок и расчёты. Расчётные задачи задают все необходимые размеры и допущения; их числа не следует считать конфигурациями конкретных checkpoint.

Математика доступна в конспектах и в раскрывающемся блоке после ответа. Например, attention разобран через дисперсию скалярного произведения и размерности; RoPE — через произведение матриц вращения; Swin — через число окон и пар; SigLIP — через signed logistic loss и его нормировку; DETR — через инъективное назначение. Оценка ранга logits отдельно отличена от ранга softmax на конкретном контрпримере.

Схемы охватывают BERT, ViT, Swin, CLIP, CoCa, SigLIP, NaViT, NaFlex, MoE, attention, encoder/decoder, RoPE и KV-cache; CNN — VGG, ResNet, DenseNet, MobileNet, SE, EfficientNet, ResNeXt, ResNeSt, ConvNeXt; детекторы — R-CNN/Fast/Faster, SSD, YOLOv1/v3, RetinaNet/FPN, CenterNet/CornerNet, FCOS, DETR; классические HOG+SVM и Viola–Jones. В конспектах с несколькими моделями есть переключатель вариантов. Сплошные стрелки обозначают основной поток, отдельные типы линий — shortcut, передачу контекста и обучающие связи. Число повторений и ширины задаются конкретной конфигурацией; это схемы принципов из лекций, а не спецификации всех checkpoint.

SVG строятся локально из `tools/model_diagrams.py`, без внешнего сервиса изображений или сетевых зависимостей. Для BERT явно показаны post-norm и две задачи исходного предобучения; общий encoder демонстрирует отдельный pre-norm вариант. Fast/Faster R-CNN сохраняют общую feature map для ROI, CoCa — независимый unimodal путь, DETR — отдельную обучающую ветвь matching с GT.

KaTeX, код и пояснения отображаются локально. Примеры — самостоятельно составленные учебные схемы по темам лекций, а не полные реализации pretrained архитектур. Они не исполняются в браузере и не требуют установки Python для чтения практикума. Для запуска скопированного кода нужны указанные в нём библиотеки; примеры M-RoPE и NMS явно принимают функцию из соседней темы.

## Публичный репозиторий и личные материалы

Публичная версия запускается сразу: в ней есть интерфейс, конспекты и банк вопросов. Полные тексты ноутбуков, домашние решения, изображения курса и личный прогресс в репозиторий не включаются. Файл `dist/sources.js` содержит только названия, номера уроков и сведения для ссылок на источники.

Если у вас есть локальная папка курса, подключите её:

```powershell
python -X utf8 tools/build_sources.py --course "ПУТЬ_К_ПАПКЕ_КУРСА"
```

Скрипт сохраняет тела ноутбуков в `dist/local/`, а иллюстрации — в `dist/assets/`. Обе папки исключены через `.gitignore`. В вашей исходной рабочей копии материалы уже подключены. Страница ноутбука загружает его при открытии; без локальных файлов показывает инструкцию подключения. Конспекты и тренировка работают независимо от них.

## Точность и область материала

Область вопросов ограничена темами `lesson_1`…`lesson_5` из папки `cv_course_at_mipt`. Использован локальный вариант курса на дату снимка **18.10.2026**. Список экзаменационных тем последующих уроков не добавлялся в банк вопросов. Авторы курса и лицензии компонентов указаны в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

Каждый конспект и вопрос имеет ссылку на файл и номера ячеек (нумерация с 1). Во вкладке «Полные ноутбуки» приведена **исходная запись**, в том числе незавершённые примеры и неточности. Её нельзя считать заново проверенным учебником. Эталонные формулировки находятся в конспектах. Раздел «Уточнения к материалам» отдельно описывает 14 групп исправлений и содержит ссылки на первоисточники.

В частности, уточнены: RoPE и экстраполяция; эквивариантность attention; causal/text masking и label masking; BERT и добавление новой `[MASK]`-позиции; scale и bias SigLIP; M-RoPE; logits-входы функций потерь; hard negatives SSD; два разных CenterNet. Неподтверждённые benchmark-таблицы и слухи об архитектурах закрытых моделей не используются как вопросы. Предметная сверка не является независимой экспертизой всех строк кода исходных ноутбуков.

Первичные источники для спорных мест:

## Данные и автономность

Работа приложения не вызывает сетевых запросов. Markdown и формулы отображаются локальными Marked 15.0.12 и KaTeX 0.16.22; лицензии находятся в `dist/vendor`. Внешние изображения из ноутбуков заменены ссылками; прикреплённые и сохранённые локальные изображения доступны без сети. Внешний источник откроется в новой вкладке только по вашему нажатию.

Ответы, оценки и избранное остаются в localStorage вашего браузера. Перемещение папки или открытие в другом браузере может создать отдельное хранилище, поэтому периодически выгружайте JSON в «Мой прогресс». Импорт проверяет структуру данных, заменяет статистику и избранное после подтверждения и сбрасывает текущую сессию. Исходные ноутбуки приложение не изменяет. Автоматической синхронизации с новыми версиями курса нет.

## Обновление и проверка

Редактируемый банк: `tools/content.py`, `tools/transformer_bank.py`, `tools/math_notes.py`, `tools/model_diagrams.py`. Сборка статических данных:

```powershell
python -X utf8 tools/build_sources.py
python -X utf8 tools/content.py
python -X utf8 tools/check_content.py
python -X utf8 tools/check_transformer_numbers.py
node --check dist/app.js
node --check dist/core.js
node tools/qa_math.cjs --formulas-only
node tools/qa_diagrams.cjs --layout-only
```

Без аргументов `build_sources.py` ищет курс в соседней структуре `CV_MIPT/cv_course_at_mipt`. Для другого расположения используйте `--course`. Скрипт читает ноутбуки и копирует только материал для локального просмотра, не запуская код.

Базовые проверки работают и без папки курса:

```powershell
python -X utf8 tools/check_content.py
node tools/qa.cjs --core-only
node --check dist/themes.js
```

Для браузерной проверки нужен Playwright и Chromium:

```powershell
node tools/qa.cjs <путь-к-пакету-playwright> <путь-к-chromium>
node tools/qa_transformers.cjs <путь-к-пакету-playwright> <путь-к-chromium>
node tools/qa_math.cjs <путь-к-пакету-playwright> <путь-к-chromium>
node tools/qa_diagrams.cjs <путь-к-пакету-playwright> <путь-к-chromium>
```

Проверяются все конспекты, все ноутбуки, 5 форматов ответа, сохранение сессии, итоговый разбор, экспорт/импорт и мобильная навигация. Тест запускает отдельный временный браузерный контекст и не меняет ваш учебный прогресс. Снимки интерфейса сохраняются в `qa`.

`qa_transformers.cjs` поднимает временный HTTP-сервер только на loopback и проверяет все 11 банков, полные наборы вопросов, переходы фильтров, развёрнутые ответы, сохранение прогресса и оба неоновых оформления на компьютере и телефоне. Сервер закрывается после теста. `check_transformer_numbers.py` независимо пересчитывает все 73 новых численных ответа.

`qa_math.cjs` проверяет KaTeX всех формул, все 65 тем на компьютере и телефоне, три оформления, копирование кода (в тестовый буфер), раскрытие математики после ответа и поиск по новым примерам. `check_content.py` проверяет синтаксис всех 65 Python-примеров без их запуска. Для проверки исполнения на синтетических данных можно запустить `python tools/check_math_examples.py` в среде с `torch`, `numpy`, `scipy` и `opencv-python-headless`: тест не скачивает модели и изображения.

`qa_diagrams.cjs` проверяет все 40 схем при ширине 1440 и 390 px, границы текста внутри блоков, выбор мышью и клавиатурой, варианты моделей, фильтры каталога, раскрытие схемы, три темы и сохранность прогресса. `check_content.py` проверяет источники схем, уникальность узлов, допустимые связи и отсутствие циклов в изображённом forward-графе; повторения стадий указываются явно как группы/блоки.

GitHub Actions выполняет этот тест в отдельном Linux job с CPU PyTorch 2.14.1, NumPy 2.2.6, SciPy 1.18.1 и OpenCV 4.11.0.86. Примеры API OpenCV соответствуют ветке 4.x из лекций: HOGDescriptor отсутствует в OpenCV 5. Зависимости проверки не включаются в офлайн-приложение.
